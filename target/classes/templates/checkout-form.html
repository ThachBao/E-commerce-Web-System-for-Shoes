⚠️ QUAN TRỌNG - Kiểm tra trước khi đặt hàng:

Để checkout thành công, cần đảm bảo database có:

  1. User với id = 5 (customer)
  2. Cart với userId = 5
  3. Cart_Item trong cart đó (có sản phẩm)
  4. Product_Variant có stockQuantity > 0
  5. Product được liên kết với variant

📝 SQL để kiểm tra:

-- 1. Kiểm tra user
SELECT * FROM Users WHERE id = 5;

-- 2. Kiểm tra cart
SELECT * FROM Cart WHERE userId = 5;

-- 3. Kiểm tra cart items
SELECT ci.*, pv.sku, pv.stockQuantity, p.name
FROM Cart_Item ci
JOIN Cart c ON ci.cartId = c.id
JOIN Product_Variant pv ON ci.variantId = pv.id
LEFT JOIN Product p ON pv.productId = p.id
WHERE c.userId = 5;

-- 4. Nếu không có, tạo dữ liệu mẫu:
-- INSERT INTO Cart (userId, createdAt, updatedAt) VALUES (5, NOW(), NOW());
-- INSERT INTO Cart_Item (cartId, variantId, quantity) VALUES (1, 1, 2);

📝 Lưu ý:

  • Đơn hàng sẽ được tạo cho customer ID = 5
  • Cần có Cart và Cart_Item trong database
  • Sản phẩm phải có đủ tồn kho
  • Nếu có lỗi, message sẽ hiển thị ở trên form này
